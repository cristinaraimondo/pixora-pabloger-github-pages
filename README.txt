PIXORA × PABLOGER — portfolio para GitHub Pages

Contenido
- index.html: página lista para publicar desde la raíz del repositorio.

Publicación
1. Creá un repositorio nuevo en GitHub.
2. Subí index.html a la raíz del repositorio.
3. En Settings > Pages, seleccioná Deploy from a branch, la rama main y la carpeta /(root).
4. Guardá los cambios y esperá a que GitHub Pages publique el sitio.

Antes de publicar
- El botón de contacto abre el portfolio de Pabloger en Behance.
- Reemplazá ese destino cuando Pixora tenga un correo, WhatsApp o formulario propio.
